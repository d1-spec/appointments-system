# Sistema de Turnos para Veterinaria

Proyecto desarrollado como parte de la materia **Conceptos de Programación** (2025).  
El objetivo es gestionar clientes, mascotas y turnos de una veterinaria de forma simple.

---

## Funcionalidades
- Registro de clientes (nombre, contacto, mascota).
- Asignación de turnos a clientes.
- Listado de turnos registrados.
- Menú interactivo en consola para navegar entre opciones.

---

## Tecnologías utilizadas
- **Lenguaje:** C#
- **Framework:** .NET
- **Interfaz:** Consola
- **IDE:** Sharpdevelop
